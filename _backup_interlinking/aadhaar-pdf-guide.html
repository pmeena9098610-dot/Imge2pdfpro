e-Aadhaar Password Kaise Kholein?

UIDAI ki taraf se aane wali PDF ka password ek standard format follow karta hai: Apke naam ke pehle 4 letters (Capital mein) + Apka Birth Year. Jaise agar apka naam RAHUL hai aur birth year 1995 hai, toh password RAHU1995 hoga. Agar naam 3 letters ka hai (jaise RAJ), toh password RAJ1995 hoga.

Scenario Password Example
Name: SURESH KUMAR, Year: 1990 SURE1990
Name: SAI, Year: 1998 SAI1998 (only 3 letters)
Name: P. KUMAR, Year: 2000 P.KU2000 (includes spaces/punctuation if any)

Kai baar forms bharte waqt aapse pucha jata hai ki document upload karein. Portal par password-protected PDF upload karne se error aa jata hai. Aise me apko us file ko Chrome browser me khol kar 'Print' > 'Save as PDF' karke password hata dena chahiye, uske baad hi upload karein.
